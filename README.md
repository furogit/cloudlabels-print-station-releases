# Cloudlabels Print Station

Downloads for Cloudlabels Print Station, the Windows program that prints labels from [Cloudlabels](https://www.cloudlabels.io) without the browser print dialog.

Download `Cloudlabels.PrintStation-win-Setup.exe` from the [latest release](https://github.com/furogit/cloudlabels-print-station-releases/releases/latest) and run it. The program updates itself.

This repository holds release files only. Help: [Cloudlabels](https://www.cloudlabels.io/contact/).
